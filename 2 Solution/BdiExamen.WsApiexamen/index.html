BdiExamen - Web API

API de exámenes. Esta es una API de servicio (sin interfaz gráfica). Los endpoints disponibles son:

MétodoURLDescripción
POST/api/examen/agregarAgrega un examen (body: { nombre, descripcion })
PUT/api/examen/actualizarActualiza un examen (body: { id, nombre, descripcion })
DELETE/api/examen/eliminar/{id}Elimina un examen por id
GET/api/examen/consultarConsulta exámenes (query: id, nombre, descripcion)
